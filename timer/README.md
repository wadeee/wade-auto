# 倒计时提醒

一个始终置顶的桌面小工具：三个按钮分别启动 10 秒、15 秒、20 秒倒计时。
倒计时结束时播放系统提示音并弹出提醒，提醒 3 秒后自动消失。

支持**全局快捷键**：在任何程序窗口中，用小键盘连按 `1` 五次启动 10 秒倒计时，
连按 `2` 五次启动 15 秒，连按 `3` 五次启动 20 秒。

## 直接运行

双击 `dist\倒计时提醒.exe` 即可（已打包好，无需安装 Python）。

也可以源码运行：

```bash
python timer.py
```

## 使用说明

- **始终置顶**：窗口不会被其他窗口挡住，拖动标题栏可移动到任意位置。
- **开始倒计时**：点击「10 秒 / 15 秒 / 20 秒」中的任意一个。
- **切换时长**：倒计时过程中点击其他时长按钮，会立即以新时长重新开始。
- **停止**：点击底部的「停止」可取消当前倒计时，不会触发提醒。
- **结束提醒**：屏幕中间弹出「时间到！」，3 秒后自动消失；也可以点击提示提前关闭。

## 全局快捷键

| 操作 | 效果 |
|---|---|
| 小键盘连按 `1` 五次 | 启动 10 秒倒计时 |
| 小键盘连按 `2` 五次 | 启动 15 秒倒计时 |
| 小键盘连按 `3` 五次 | 启动 20 秒倒计时 |

判定规则：

- 只认**小键盘（数字键区）**的 1 / 2 / 3；大键盘数字行的 1 / 2 / 3 不会触发。
- NumLock 开启、关闭都可以正常触发。
- 任何程序在前台时都有效，不需要先切换到本工具。
- 相邻两次按键间隔不超过 **1 秒**，总共连按 5 次即可触发。
- 按住不放产生的自动重复不算按键；中途按下其他键会重新计数。
- 按住 Shift / Ctrl / Alt / Win 的组合键不算，避免输入符号时误触。
- 因为快捷键是全局的，在小键盘上快速连打同一个数字五次（例如在表格里输入 `11111`）
  也会触发，这是按需求的预期行为。

## 重新打包

双击 `build.bat`，生成 `dist\倒计时提醒.exe`。

首次构建会自动创建构建环境 `venv`（复用系统已安装的 PyInstaller，缺失时会尝试
`pip install pyinstaller`）。新版 setuptools 移除了 `pkg_resources`，直接使用
全局 Python 会让 PyInstaller 无法启动，所以这里单独使用一个 venv 来打包。

也可以手动执行：

```bash
python build.py
```
